# CampusFlow dashboard prototype

Open `index.html` directly in a modern browser. No build step or local API is required.

The prototype uses synthetic sample data in `app.js`. Navigation, student search/class/section filters, fee status updates, and responsive navigation work locally in the browser. The add-student and add-class buttons are design placeholders; production forms and API integration are described in `../../docs/school-erp-ui-architecture-and-plan.md`.

The campus image is generated sample artwork and is not a photo of the actual school.
